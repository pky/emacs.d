#+TITLE: org 早見表
#+STARTUP: showall

C-c h でこのファイルを開く。q で閉じる。

* まず覚える一つ
- 見出しの文字の頭(* と空白の後ろ)で ? : この早見表が開く
- C-c h : どこからでもこの早見表が開く
- q : この早見表を閉じる
- F1 m : いまのモードのキー一覧(英語)。C-h は削除に割り当て済み
- C-c b : 全キーバインドの検索(helm-descbinds)

* 見出しの文字の頭で押す一文字コマンド
カーソルを見出しの文字の頭に置き、そのまま1キー押す。本文の途中では普通の文字入力になる。
- n / p : 次 / 前の見出しへ
- f / b : 同じ階層で次 / 前の見出しへ
- u : 一つ上の階層へ
- j : 見出しを検索して飛ぶ
- c : 折りたたみ切り替え
- C : 全体の折りたたみ切り替え
- s : この見出しだけを表示(もう一度で戻る)
- t : TODO 状態の切り替え
- r / l : 見出しを降格 / 昇格
- U / D : 見出しを上 / 下へ入れ替え
- i : 見出しを追加
- k : 見出しを丸ごと切り取り(消える。貼り付けは C-y)
- a : アーカイブへ移動(確認あり)
- o : リンクを開く
- v : アジェンダ

* 見出し
- Tab : 見出しの折りたたみ切り替え
- S-Tab : 全体の折りたたみ切り替え
- M-Left / M-Right : 見出しの昇格 / 降格
- M-Up / M-Down : 見出しを上下に入れ替え
- M-Return : 同じ階層の見出しを追加

* チェックボックスとリスト
- C-c C-c : チェックボックスの切り替え。[ ] が未完了、[X] が完了
- 完了は大文字の X。小文字の x は完了として扱われない
- M-Return : リストの項目を追加
- M-S-Return : チェックボックス付きの項目を追加

* リンク
- C-c C-l : リンクの挿入と編集
- C-c C-o : カーソル位置のリンクを開く
- 形式は [[url][表示名]]

* TODO(todo.org)
- C-c C-t : 状態の切り替え(TODO DOIN WAIT SOMEDAY REMD DONE SKIP)
- C-c a : アジェンダ
- C-c s : アジェンダ検索
- C-c A : DONE をアーカイブへ移動

* スケジュールと期限(todo.org)
見出し(* TODO ...)の上で押す。アジェンダに載るのは todo.org と todo_*.org だけ。
- C-c C-s : 予定日を設定(この日に着手する)
- C-c C-d : 期限を設定(この日までに終える)
- C-c . : 本文中に日付を挿入
- 日付の入力欄(カレンダーが出る):
  - S-Left / S-Right : 1日戻す / 進める
  - S-Up / S-Down : 1週間戻す / 進める
  - 文字でも入れられる : +1d(明日) +1w(1週間後) fri(次の金曜) 11/25 2026-11-25 10:00
  - Enter : 確定
- C-c C-s や C-c C-d をもう一度押すと日付を変更できる。消すときは C-u C-c C-s / C-u C-c C-d

* アジェンダ(C-c a)
- C-c a a : 今週の予定と期限の一覧
- C-c a t : TODO の一覧
- f / b : 次の週 / 前の週へ
- d / w : 日表示 / 週表示
- . : 今日へ戻る
- Enter : その項目の場所へ移動
- t : TODO 状態の切り替え
- S-Right / S-Left : 予定日を1日後ろ / 前へずらす
- r : 表示を更新
- q : 閉じる

* 日次ダッシュボードの期限
ダッシュボードでは DEADLINE や SCHEDULED を使わない。期限は「11/25（火）まで」のように普通の文字で書く。daily-update が拾って「期限あり」の欄に載せる。

* 書式
- *太字* 、/斜体/ 、~コード~ 、=等幅=
- 記号を隠しているときは、カーソルを置くと見える

* ダッシュボード(01-Dashboard)
- 見出しは * ** *** 。Markdown の # ではない
- 自動で整理案が付く欄は、採用した行を自分で消す
